# Change: Add book reader and report archive

## Why
Turn the "Growing Talos Worshipers" slide deck into a permanent, extensible
website presenting RP reports as Skyrim in-game books.

## What Changes
- New `book-reader` capability (two-page spread, page-turn leaf, folio/running head)
- New `report-archive` capability (parchment ledger index from content collection)
- First report migrated from Google Slides to Markdown with explicit page breaks

## Impact
- New specs: book-reader, report-archive
- New code: entire Astro project
